# CS 229 HW3 Extra Credit Report

LaTeX report for HW3 extra credit experiments (EC1, EC2, EC3, EC7) on emoji flow matching.

## Structure

- `main.tex` — document root
- `sections/` — one `.tex` file per EC experiment
- `figures/` — plots exported from executed notebooks in `../hw3-ec*.ipynb`

## Build

```bash
pdflatex main.tex
```
