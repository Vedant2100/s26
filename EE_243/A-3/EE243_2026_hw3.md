## Problem 2 — Fundamental Matrix Estimation (3 pts)

Use the stereo pair:

- `viprectification_deskLeft.png`
- `viprectification_deskRight.png`

(from the DATASETS folder).

### Steps

1. Load the images and detect key points (corner points) using any predefined corner detector in Python (see Assignment 1).
2. Obtain feature descriptors for corners using the **ResNet50** model from Assignment 3.
   - Use **8×8 patches** around each corner.
   - Pad or resize patches before feeding them into the model if needed.
3. Match points and use the **8-point algorithm** to obtain the fundamental matrix **F**.
   - Use random subsets of 8 points to estimate a set of fundamental matrices.
   - For each candidate **F**, compute the **mean error** on the remaining matched points using **Sampson distance**.
4. **Report:**
   - The fundamental matrix with the **least error**
   - The corresponding **mean error**

> **Constraint:** Do **not** use built-in functions to estimate the fundamental matrix.

### Sampson Distance

For matched points \(\mathbf{x}\) and \(\mathbf{x}'\) (2D image-plane coordinates):

\[
d_{\text{Sampson}} = \frac{(\mathbf{x}^T F \mathbf{x}')^2}{\|F^T \mathbf{x}\|_2^2 + \|F \mathbf{x}'\|_2^2}
\]

## Problem 3 — 3D Gaussian Splatting (4 pts)

1. Capture a short video (**30 s–1 min**) on/near **UCR campus** with your phone.
   - Prefer a **mostly static scene** with **sufficient parallax** (walk around the subject; avoid panning in place).
2. Extract frames at a sensible rate (~**300 frames**).
3. Run **COLMAP** (or equivalent SfM) to recover per-frame camera poses \(\{R_i, t_i\}\) and intrinsics **K**.

4. Optimize a **3D Gaussian Splatting** model on the captured frames (official 3DGS implementation).
5. Render an image at **every GT pose**, assemble renders in capture order into a video at the **same frame rate** as the input.
6. Produce a **side-by-side video**: GT frames (left) vs 3DGS renders (right), **time-aligned** frame by frame.
